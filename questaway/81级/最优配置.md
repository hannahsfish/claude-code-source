# 81 级最优配置（引擎实测）

基于 11 月 7 日存档：四人 81 级，挂 6-3。
- 刷图：6-3，每组 60 个种子。
- 巨像：10 种巨像全测，强度 1561，比相对值。

## 一、推荐方案对比

| 方案 | 刷图经验 | 金币 | 巨像 |
|---|---|---|---|
| 现在 | 基准 | 基准 | 52.9B |
| A：只换宝石（见第二节） | +1.4% | +1.1% | 58.4B（+10.5%） |
| **B：A + 刺客冰元素** | **+3.9%** | +1.5% | 59.7B（+12.8%） |
| **C：B + 武僧混沌元素** | +2.5% | −1.6% | **68.9B（+30.4%）** |
| D：A + 武僧混沌元素（刺客不换） | 0 | −2.2% | 67.8B（+28.2%） |

- **只看刷图：选 B。**
- **刷图和巨像兼顾：选 C。** 刷图比 B 少 1.4%，巨像多 17%。

## 二、宝石（所有方案都要做）

| 位置 | 现在 | 改成 | 单独效果 |
|---|---|---|---|
| 武僧武器（5 孔） | 二阶穿透 ×5 | **三阶红宝石 ×5** | 刷图 +0.9%，巨像 +5.5% |
| 刺客武器（4 孔） | 穿透 ×4 | **处决组合：翡翠、翡翠、红宝石、穿透（按顺序，三阶）** | 巨像 +2.9% |
| 弓手副手（5 孔） | 二阶穿透 ×5 | **三阶红宝石 ×5** | 刷图 +0.5%，巨像 +3.3% |

- 宝石组合必须按顺序镶满，组合加成按最低阶宝石算。
- 武僧防具上的穿透**不要换**：换成易伤后刷图 −0.8%。
- 刺客其余穿透、弓手防具穿透：换不换差别很小。

## 三、元素附魔（方案 B / C）

**刺客：武器附五阶冰元素**（会顶掉攻击附魔）
- 刷图、巨像两套配置都用同一棵冰系树：新增核心「元素吐息」「永冬」，去掉「冷血杀手」。
- 技能不变：刷图用暗影系，巨像用处决系。
- 图：`刺客_冰元素天赋树_对比刷图.png`、`刺客_冰元素天赋树_对比巨像.png`

**武僧：武器附五阶混沌**（方案 C）
- 刷图、巨像两套配置都用同一棵混沌树：新增核心「元素吐息」「原初混沌」；刷图配置去掉「玻璃大炮」。
- 刷图技能：风系不变。
- **巨像技能：改成灵魂系**，主动技能是灵魂狂击、灵魂打击、宁静光环；气波、宁静光环、灵魂打击、灵魂狂击各 10 点。
- 图：`武僧_混沌天赋树_对比刷图.png`、`武僧_混沌天赋树_对比巨像.png`

**测过但不推荐的**
- 弓手：任何元素附魔都没用。元素箭系巨像 −34%。
- 刺客其他元素：火 +0.8%，雷、混沌更低。
- 武僧冰元素：巨像只有 +7.5%。
- 元素宝石（海蓝宝石、黑曜石）都不如红宝石。

## 四、代码里查到的其他机制

| 机制 | 结论 |
|---|---|
| **装备强化 +1～+10** | 每级把这件装备的词条乘 (1 + 5%～12%)，传说品质是 11%。每 +3/+6/+9 有个里程碑，用巨像核心「唤醒」后，对应词条额外 +50%。**代价很高**：同品质装备喂 1 件算 1 点经验，低一档算 1/4，低两档算 1/16；+3 要 9 点，+5 要 21 点，+10 要 100 点，另外还要金币，传说 60 级装备 +5 约 85 万。单件 +2：刷图 +0.3～1.0%，巨像 +1～5%。适合把多余的神话、传说装备喂给主力装备。 |
| 法阵 | 加成对全队、所有模式生效。见 80 级的结论。 |
| 宠物 | 模拟里换宠物对刷图没有影响。 |
| 指定属性卷轴（工作台） | 只能在锻造时加一条词条，锻造只能出到史诗，用处不大。 |
| 宝石组合 | 5 孔武器能用的组合都是元素系，只有刺客 4 孔武器的「处决」值得用。 |

## 五、天赋树复核
- 冰系刺客树：在方案 C 下重新筛了 935 棵刷图树、153 棵巨像树，现在这棵仍是第一（巨像差 0.4% 以内）。
- 混沌武僧树：在方案 C 下重新筛了 937 棵刷图树、184 棵巨像树，刷图、巨像都是第一。
- 武僧巨像技能组合：灵魂狂击 + 灵魂打击 + 宁静光环最好（68.9B），风系只有 61.4B。
- 刺客巨像技能：处决系仍然最好。
