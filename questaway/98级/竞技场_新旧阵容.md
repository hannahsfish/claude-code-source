# 竞技场：现阵容和新阵容对比（savedata120）

用游戏自带的竞技场引擎（1.0.9）模拟。每个对手进攻、防守各 20 场。

口径：
- 所有英雄按 100 级算。武僧、刺客、治疗师、弓箭手用存档里的真实装备和竞技场配法（竞技场配法还是 94 点的，有 4 点天赋没分配）。
- 工程师、女巫用之前 100 级筛出来的竞技场配法（工程师奇巧装置系，女巫腐化系），装备按传说 60 或 80 生成，宝石三阶。
- 对手是之前 100 级筛选时留下的 13 套优化阵容，装备分别缩到传说 60、80 和原来的 100。它们不是真实天梯上的对手。

| 我方 | 对手 60 级装备（攻 / 守） | 对手 80 级装备 | 对手 100 级装备 |
|---|---|---|---|
| 现阵容（武僧、刺客、治疗师、弓箭手） | 5% / 4% | 0% / 0% | 0% / 0% |
| 只把武僧换成工程师（传说 60） | 12% / 12% | 1% / 1% | 0% |
| 只把弓箭手换成女巫（传说 60） | 21% / 25% | 0% | 0% |
| 新阵容，工程师女巫传说 60 | 76% / 74% | 0% / 1% | 0% |
| 新阵容，传说 60 + 三件永恒（手持炮 +3 唤醒、导能手套、秘法头环） | 94% / 97% | 3% / 4% | 0% |
| 新阵容，工程师女巫传说 80 | 100% / 100% | 9% / 10% | 0% |

互打：新阵容进攻现阵容 100%，现阵容进攻新阵容 0%（三种装备档都一样）。

之前在 100 级、双方都是一身传说 100 的同等条件下做过 13 套阵容的循环赛：刺客 + 工程师 + 女巫 + 治疗师进攻胜率 89%、防守 87%，排第 2（第 1 是圣骑士 + 工程师 + 女巫 + 治疗师，89% / 89%）；武僧 + 刺客 + 治疗师 + 弓箭手 18% / 12%，排最后。

结论：
- 新阵容在竞技场的优势比在巨像里还大，而且必须两个一起换，单换一个提升有限。
- 三件永恒对竞技场很值：同样的传说 60，胜率从 76% 到 94%。
- 装备等级是硬门槛：对手整体高一档（80 对 60）时，换阵容也打不过。

## 更正：换成不带女巫的对手池重测

前面所有竞技场数字用的 13 套对手里有 12 套带女巫，而实际天梯上女巫不多（一场巨像的 5 支同行队伍里：治疗师 5、法师 4、骑士 3、弓箭手 3、工程师 2、圣骑士 1、野蛮人 1，女巫 0）。
所以另外配了 11 套不带女巫的对手（骑士 / 圣骑士 / 野蛮人做前排，法师、弓箭手、工程师、刺客、武僧做输出，治疗师），配法取自之前 100 级的筛选，装备按档位生成。每个对手进攻防守各 20 场，表里是进攻 / 防守胜率。

| 我方 | 对手 60 级 | 65 级 | 70 级 | 80 级 | 90 级 | 100 级 |
|---|---|---|---|---|---|---|
| 现阵容（武僧、刺客、治疗师、弓箭手） | 72 / 81 | 59 / 56 | 50 / 52 | 46 / 44 | 41 / 42 | 20 / 20 |
| 新阵容，工程师女巫传说 60 | 100 / 100 | 99 / 99 | 95 / 93 | 77 / 74 | 60 / 60 | 54 / 52 |
| 新阵容，传说 60 + 四件永恒 | 100 / 100 | 100 / 100 | 100 / 100 | 87 / 89 | 68 / 66 | 57 / 57 |
| 新阵容，工程师女巫传说 80 + 四件永恒 | — | — | — | 100 / 100 | 99 / 97 | 76 / 79 |

同样的队伍对两套带女巫的对手（圣骑士或骑士 + 弓箭手 + 女巫 + 治疗师）：现阵容 3% / 0% / 0%（60 / 65 / 70 级），新阵容传说 60 是 40% / 0% / 0%，加四件永恒是 100% / 100% / 53%。

在「新阵容 + 四件永恒」上换配置（对无女巫对手，80 / 90 / 100 级）：

| 改动 | 80 级 | 90 级 | 100 级 |
|---|---|---|---|
| 推荐配置（女巫防具首饰紫水晶 + 攻击附魔，工程师全红宝石） | 87 / 89 | 68 / 66 | 57 / 57 |
| 女巫改全红宝石 | 76 / 76 | 61 / 64 | 55 / 54 |
| 女巫改冷却附魔 | 80 / 80 | 64 / 65 | 57 / 59 |
| 女巫防具改黑曜石 | 71 / 75 | 62 / 63 | 55 / 54 |
| 女巫防具改钻石 | 72 / 75 | 61 / 62 | 52 / 52 |
| 工程师防具改黑曜石 | 92 / 91 | 67 / 69 | 57 / 56 |
| 工程师防具改钻石 | 94 / 97 | 74 / 75 | 59 / 57 |
| 工程师手持炮改诅咒宝石 | 87 / 89 | 67 / 66 | 57 / 56 |

结论：
- 新阵容的优势在没有女巫的对手面前依然成立，但没有之前说的那么悬殊：现阵容对同档装备的无女巫对手有五成到八成胜率，之前的「5%」是被女巫对手压出来的。
- 女巫的配置（防具和首饰紫水晶、攻击附魔）在两种对手池里都是最好的，结论稳定。
- 工程师防具镶黑曜石只在对手有女巫时才值；对没有女巫的对手，镶钻石反而更好（+7 个百分点）。两者在巨像里都要掉伤害。
