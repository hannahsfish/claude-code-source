## 紫水晶为什么有用：是急速，不是施法速度

四阶紫水晶同时给急速和施法速度。镶满 33 个空孔后，女巫竞技场面板的急速从 7477 涨到 17182，施法速度从 19195 涨到 29024。把两项拆开单独加到女巫身上（对手传说 100，384 局）：

| 只改女巫的 | 进攻胜率 | 平均对局时长 |
|---|---|---|
| 不改 | 37.5% | 40.7 秒 |
| 只加施法速度 | 37.5%（逐局结果完全相同） | 40.7 秒 |
| 只加急速 | 53.9% | 42.7 秒 |
| 两项都加（= 镶紫水晶） | 53.9% | 42.7 秒 |

女巫的竞技场配法是鲜血系：汲取生命（吸血）、血之飞翔（骑着镰刀快速挥砍，期间近战打不中她）、血爆、血祭（全队每次命中吸血）。这一系靠镰刀普通攻击出伤害和吸血，出手频率看急速。巨像用的诅咒系是放技能，所以紫水晶在巨像只有 +1.7%。

其他给女巫加急速的办法（同样的 64 套对手）：

| 方案 | 对手传说 90 | 对手传说 100 |
|---|---|---|
| 现在 | 53 / 55 | 37 / 38 |
| 空孔镶四阶紫水晶 | 72 / 66 | 54 / 47 |
| 不镶，8 个非冷却附魔位改附急速 | 59 / 59 | 50 / 46 |
| 不镶，全部附魔改急速（丢掉冷却） | 68 / 67 | 53 / 50 |
| 紫水晶 + 8 个非冷却附魔位改急速 | 74 / 65 | 55 / 50 |
| 紫水晶 + 武器 5 颗红宝石也换紫水晶 | 71 / 67 | 53 / 49 |
| 紫水晶 + 项链 3 颗诅咒也换紫水晶 | 73 / 69 | 57 / 47 |

镶满空孔之后再加急速，差别都在误差内（±2.5 点）。
