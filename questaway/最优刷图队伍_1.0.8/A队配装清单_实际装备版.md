# A 队配装清单 · 实际装备版（1.0.8）

基于 11 月 3 日存档（武僧 / 刺客 / 牧师 / 弓手，均 65 级，挂深渊 1-5），用游戏自带 1.0.8 引擎逐项实测。
基准：593 万经验/小时（模拟值，战斗 + 每图 4 秒切图）。

> 与旧版清单的区别：旧版按「整队理想神话装」计算，且模型里的攻速、施法速度、冷却缩减、暴伤词条数值比 1.0.8 实际物品高一倍。本版改用真实物品数值，并在你的真实存档上测。

## 通用规则

| 英雄 | 附魔 | 宝石 | 首饰底子（新买时） |
|---|---|---|---|
| 武僧 | 攻击 | 穿透（三阶 > 红宝石） | 中型（Fine Thread / 中型戒指 / 中型手镯）；项链中型 ≈ 暴击 |
| 刺客 | 攻击 | **红宝石**（三阶红宝石 +1.25% > 穿透 +0.27%） | 中型 |
| 弓手 | 攻击 | 红宝石 ≈ 穿透（现有穿透不用换） | 中型 |
| 牧师 | 移速 | 对经验无影响，继续用黄玉（加金币） | 对经验影响 < 1%，按金币需求选 |
